# ROCK C WEAR — تطبيق Android

يتيح تطبيق **ROCK C WEAR** تصفّح منتجات العلامة التجارية وزيارة متجرها الرسمي من هاتف Android.

[زيارة متجر ROCK C WEAR الرسمي](https://rockcwear.myeasyorders.com/)

## تنزيل التطبيق

افتح [صفحة الإصدارات](https://github.com/ahmedharhashofficial/ROCKC-WEAR-Downloads/releases)، واختر الإصدار الذي تريده، ثم اضغط على **ROCKC-WEAR.apk** ضمن **Assets** لتنزيل التطبيق.

## التحقق من نسخة التنزيل

قارن بصمة SHA-256 لملف APK الذي نزّلته بالبصمة المرفقة مع الإصدار.
